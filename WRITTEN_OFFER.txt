Written Offer of Source (GPL-3 §6)
==================================

The complete corresponding source code for the GPL-3 components in this
Haritica cloud GPL-extras image is publicly available from the upstream
maintainers at the exact versions shipped in this image:

    HISAT2 v2.2.1:           https://github.com/DaehwanKimLab/hisat2
    subread v2.0.6:          https://sourceforge.net/projects/subread/
    leidenalg:               https://github.com/vtraag/leidenalg
    louvain:                 https://github.com/vtraag/louvain-igraph
    igraph (python):         https://github.com/igraph/python-igraph

The thin wrapper scripts that aggregate these tools (entrypoint.sh,
run_alignment.py, run_clustering.py, Dockerfile) are published in the
Haritica project source tree at:

    https://github.com/ThomasXielt/haritica-cloud-gpl-extras

at the tag matching this image's version (v1.0.2) and the hisat2-v2.2.1
tag for the Windows binary archive. Every cloud deployment of this image
is pinned to a specific tag in `infra/config/environments.ts` and the
mirror-repo tag with that name carries the exact source used to build it.

For at least three (3) years from the date this image was distributed,
and for as long as Haritica offers support for this product, we will
provide — to any third party who possesses this image — a complete
machine-readable copy of the corresponding source code for the GPL-3
components listed above, on a physical medium customarily used for
software interchange, for a charge no more than the cost of physically
performing the distribution. Contact licensing@haritica.com.

This image is GPL-3.0-or-later as a whole (the aggregate work). The
closed-source main Haritica image (haritica-{env}-api / -worker) does not
incorporate this image at runtime; communication between the two stages
happens exclusively via S3 (FSF "mere aggregation"). See
docs/LICENSING-CLOUD.md in the main repo for the full architecture.
